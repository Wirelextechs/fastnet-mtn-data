🔌 API Endpoints

1. Fetch Transactions

Method: GET

Endpoint: /fetch-transactions

Full URL: https://reseller.dakazinabusinessconsult.com/api/v1/fetch-transactions

Description: Get transaction history for the authenticated user

Authentication: API Key required

Request Headers:

3. Buy Data Package (Single)

Method: POST

Endpoint: /buy-data-package

Full URL: https://reseller.dakazinabusinessconsult.com/api/v1/buy-data-package

Description: Purchase a single data package

Authentication: API Key required

Request Headers:

Content-Type: application/json
Accept: application/json
x-api-key: {your_api_key}

Request Body:

{
  "recipient_msisdn": "0551053716",
  "network_id": 3,
  "shared_bundle": 12,
  "incoming_api_ref": "unique_reference_003"
}

Request Parameters Explanation:

Parameter

Type

Description

recipient_msisdn

String

Phone number of the recipient (mobile number)

network_id

Integer

Network identifier (e.g., 3 for a specific network)

shared_bundle

Integer

Bundle/package ID to purchase

incoming_api_ref

String

Unique reference for tracking this transaction

cURL Example:

curl --location 'https://reseller.dakazinabusinessconsult.com/api/v1/buy-data-package' \
--header 'Content-Type: application/json' \
--header 'Accept: application/json' \
--header 'x-api-key: dk_2uU6jK7JfGEPZrTvqzUXv9ZK3JJ3D9mO' \
--data '{
  "recipient_msisdn": "0551053716",
  "network_id": 3,
  "shared_bundle": 12,
  "incoming_api_ref": "unique_reference_003"
}'

📊 Response Format

All endpoints return JSON responses. The documentation indicates that responses include:

Body: Response data (varies by endpoint)

Headers: Response headers information

🔑 Key Integration Points

Always include the API key in the x-api-key header for all requests

Use JSON format for request bodies (Content-Type: application/json)

Unique References: Use the incoming_api_ref parameter to track transactions uniquely

Bulk Operations: For multiple purchases, use the bulk endpoint to optimize API calls

Phone Format: Ensure phone numbers (msisdn) are in the correct format for the target network
